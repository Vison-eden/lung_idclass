# CT-based multimodal lung adenocarcinoma classification

Repository for the manuscript **CT-based multimodal models for lung adenocarcinoma spectrum identification and invasiveness classification**.

## Overview

This study evaluates CT-based multimodal models for two pathological classification tasks:

1. **Spectrum identification:** distinguishing adenocarcinoma-spectrum lesions from squamous and small-cell carcinomas.
2. **Invasiveness classification:** classifying adenocarcinoma-spectrum lesions as atypical adenomatous hyperplasia/adenocarcinoma in situ (AAH/AIS), minimally invasive adenocarcinoma (MIA), or invasive adenocarcinoma (IAC).

The models integrate three-dimensional CT with structured radiological measurements. Routine clinical information is additionally incorporated for spectrum identification.

## Code availability

The source code, configuration files, and instructions for training and inference will be released in this repository upon acceptance of the manuscript.

The repository currently contains the project overview and license. Patient-level imaging and clinical data are not distributed through this repository.
